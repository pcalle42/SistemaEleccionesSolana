# Documentación

Los documentos numerados en este directorio son las especificaciones de
construcción vigentes. Las carpetas temáticas reciben documentación adicional
sin dispersar ni mover parcialmente la secuencia numerada.

- `architecture/`: vistas y decisiones consolidadas.
- `build/`: guías ejecutables adicionales de construcción.
- `security/`: modelos de amenazas y controles.
- `operations/`: runbooks y recuperación.
- `adr/`: decisiones arquitectónicas nuevas.

La cadena de CI/CD y release está descrita en
[`18-ci-cd-calidad-release.md`](18-ci-cd-calidad-release.md) y su operación en el
[runbook de release](operations/release-runbook.md).

La operación, observabilidad y recuperación se especifican en
[`19-observabilidad-operacion-backup-recuperacion.md`](19-observabilidad-operacion-backup-recuperacion.md)
y se materializan en [`operations/`](operations/README.md).
