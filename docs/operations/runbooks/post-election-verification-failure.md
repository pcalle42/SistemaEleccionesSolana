# Fallo de verificación post-electoral

## Síntomas

Package oficial, tally o publicación no verifica.

## Impacto

SEV1 de integridad; resultado no es publicable/confiable.

## Alertas

Offline verifier y result/package verification.

## Checks seguros

Congelar objetos, comparar digests, manifests, snapshots y audit.

## Contención y recuperación

Suspender publicación y analizar causa sobre copias preservadas.

## Verificación

Repetición independiente reproducible con evidencia explicada.

## Escalamiento

Auditor, criptografía, seguridad y autoridad electoral.

## Acciones prohibidas

No modificar package repetidamente hasta que pase ni ocultar versión fallida.

## Evidencia a preservar

Package, report, digests, release, DB references y timeline.
