# Incidente de seguridad

## Síntomas

Credencial, integridad o acceso puede estar comprometido.

## Impacto

SEV1/SEV2 según boundary y elección.

## Alertas

Security gates, IAM, artifact/DB integrity y audit.

## Checks seguros

Seguir threat model; limitar acceso y no divulgar secretos.

## Contención y recuperación

Aislar componente, preservar evidencia y rotar según runbook probado.

## Verificación

Digests, audit, sesiones, release y recovery completos.

## Escalamiento

Seguridad, incident commander, auditor y autoridad electoral.

## Acciones prohibidas

No destruir evidencia ni alterar estado electoral para ocultar impacto.

## Evidencia a preservar

Chain-of-custody, alertas, accesos, digests y acciones.
